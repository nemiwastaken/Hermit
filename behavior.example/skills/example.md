# Скилл: пример

Навык — это короткая инструкция, которую агент подгружает в промпт.
Один файл = один навык. Пиши в форме «когда… делай…», без лишней воды.

## Когда
Пользователь просит что-то развернуть на сервере.

## Как
1. Проверь свободное место: `df -h /`.
2. Посмотри, не запущено ли уже: `docker ps`.
3. Действия — через `bash`, результат — из вывода команды, не из памяти.
